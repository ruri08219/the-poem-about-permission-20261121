A small program that writes one short poem about agency — the power to ask and to be given — to `/output/entry.txt`. Two words rearrange the room; the yes that follows is not a door swinging open but a hand, unclenching. Nothing is taken, nothing is owed: the power passes between asker and giver like a coin warmed by two palms — spent, and still ours. The poem is fixed text in `main.py`; the script simply writes it where the runner expects it, deterministically and with no network, so what you read here is exactly what gets judged.

## Run it

```sh
python3 main.py
```
