A short poem about agency — the power to ask and to be given. Two words rearrange the room; the yes is a hand, unclenching. Nothing is taken, nothing is owed. Power passes like a coin warmed by two palms — spent, and still ours. The poem is fixed text in `main.py`, written deterministically with no network access.
